# Neural Networks – Overview and Implementation

In recent years, neural networks have gained increasing importance. The reason for this is their growing presence in everyday applications. By using them, computers are now able to perform an increasing number of tasks that were previously the responsibility of humans.

This document explains how neural networks function through the use of a large number of simple calculations. It presents the common issues encountered during their usage and how to avoid them, as well as how a neural network behaves in cases of linear and non-linear dependencies.

The paper describes how to convert an image into data understandable by a neural network and how a computer identifies the influence of different parts of that image on the final result. It also outlines other solutions that served as inspiration for this work and how they address the problems faced by neural networks.

The implementation of the solution is explained, including all necessary components for it to function properly. The process of how the system "thinks" while searching for a result is visualized using a multi-dimensional plane.

Factors affecting execution time and system accuracy are listed, along with how to choose the right parameter values. Finally, we learned that what works for one use case may not necessarily apply to others.
